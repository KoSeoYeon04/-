# 🎮 MULTI ARCADE — 실시간 미니게임 경쟁

친구들이 **같은 웹 주소**에 접속해 방 코드로 입장하고, **모두 같은 게임을 동시에 진행**하는 3라운드 멀티플레이 웹게임입니다.

## 게임 기능

- 방장: 게임방 생성 → 초대 링크/5자리 방 코드 복사 → 게임 시작
- 참가자: 닉네임만 입력하고 입장 (회원가입 불필요)
- **3라운드 자동 진행:** 두더지 잡기 → 장애물 피하기 → 순서 기억하기
- **25초씩 동시 플레이**, 라운드마다 3초 카운트다운 / 6초 중간 결과
- 최대 **10명**, 라운드마다 최대 **1,000점** / 총 3,000점, 실시간 순위표
- 최종 우승자 발표, 방장이 다시 시작 가능
- PC/모바일 터치 지원

## 내 컴퓨터에서 실행하기 (Windows)

1. [Python](https://www.python.org/downloads/) 설치 (설치할 때 `Add Python to PATH` 체크)
2. 폴더의 **`start_windows.bat`** 더블클릭
3. 열리는 브라우저에서 `http://localhost:8080` 접속
4. **여러 브라우저 탭**을 열면 혼자서도 다인 플레이를 테스트할 수 있습니다. 서로 다른 닉네임을 쓰세요.
5. 같은 와이파이에 있는 다른 휴대폰은 PC의 사설 IP 주소로 접속할 수 있습니다. Windows 터미널에서 `ipconfig`로 PC IP(예: `192.168.0.5`)를 확인한 뒤 휴대폰에서 `http://192.168.0.5:8080`을 엽니다. Windows 방화벽이 Python의 네트워크 접근을 허용해야 합니다.

Mac/Linux 또는 수동 실행:

```bash
python -m pip install -r requirements.txt
python server.py
```

그다음 `http://localhost:8080`에 접속합니다. 종료하려면 실행 창에서 `Ctrl+C`를 누릅니다.

## 친구들과 다른 곳에서 접속하려면

친구와 인터넷으로 접속하려면 이 프로젝트를 **WebSocket을 지원하는 웹서버에 배포**해야 합니다. 다운로드한 ZIP 자체만으로는 다른 집에 있는 친구들과 접속할 수 없습니다.

예: [Render](https://render.com/)에서 GitHub 저장소 연결 → **New → Web Service** → 빌드 명령 `pip install -r requirements.txt`, 실행 명령 `python server.py` → 배포. 프로젝트에 `render.yaml`이 포함돼 있어 Render Blueprint 방식으로도 설정 가능합니다. 배포 후 생성된 `https://...` 주소를 친구들에게 공유하면 됩니다.

> 무료 호스팅은 서비스가 유휴 상태에서 잠들거나 지연될 수 있습니다. 동시에 접속하는 동안 안정적으로 켜져 있는 서비스를 권장합니다.

## 게임 규칙

| 라운드 | 조작 | 점수 |
|---|---|---|
| 1. 두더지 잡기 | 나오는 두더지를 빠르게 탭 | 기본 45점, 콤보 보너스 최대 +30점 |
| 2. 장애물 피하기 | ← / → 키 또는 화면 버튼으로 운석 피하기 | 장애물 1회 회피당 +43점. 하트 3개 소진 시 해당 라운드 종료 |
| 3. 순서 기억하기 | 깜빡이는 4색 타일 순서 기억 → 같은 순서대로 탭 | 한 레벨 완료당 `90 + 45 × 타일 개수`점 |

각 라운드 득점은 1,000점에서 상한 적용합니다.

## 기술 구조

- **Frontend:** HTML / CSS / JavaScript (추가 빌드 도구 불필요)
- **Backend:** Python 3.10+ / aiohttp / WebSocket
- **실시간 동기화:** 서버가 방, 타이머, 라운드, 점수를 관리하고 모든 플레이어에 즉시 방송
- **점수 검증:** 서버에서 정답/충돌/시간/상한을 확인. 실제 상업 서비스로 키울 경우 추가 부정행위 탐지가 필요합니다.
- **게임 데이터:** 메모리에만 보관합니다. 서버가 재시작되면 게임방과 점수가 초기화됩니다.
- **배포 시:** WebSocket을 지원하는 단일 인스턴스를 권장합니다. 다중 인스턴스 배포는 Redis 등 공유 상태 저장소 추가가 필요합니다.

## 설정 변경

```bash
# macOS / Linux 예시: 라운드 20초, 중간 결과 5초
ROUND_LENGTH=20 BREAK_LENGTH=5 python server.py
```

기본 `PORT=8080`, `ROUND_LENGTH=25`, `BREAK_LENGTH=6`, `COUNTDOWN_LENGTH=3`.

## 주의

이 예제는 친구 사이에 즐기는 프로토타입입니다. 인앱 결제, 영구 랭킹, 계정, 비밀번호, 영구 기록은 아직 없으며, 서버 재실행 시 기록이 지워집니다.
